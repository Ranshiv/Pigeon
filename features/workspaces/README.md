# Workspaces Feature

## Overview

Workspaces serve as the foundational organizational unit in Pigeon, providing dedicated environments for teams to collaborate on API development and testing.

### Key Components

#### 1. Workspace Types

- **Personal Workspaces**
  - Private, individual workspace
  - Automatic creation for new users
  - Full control over content and settings
- **Team Workspaces**
  - Collaborative environment for teams
  - Role-based access control
  - Real-time collaboration features
- **Public Workspaces**
  - Visible to all community members
  - Great for open-source projects
  - Public API documentation

#### 2. Role Management

- **Admin**: Full control over workspace settings and member management
- **Editor**: Can edit collections and approve merges
- **Viewer**: Read-only access to workspace content

#### 3. Real-Time Collaboration

- Live member presence indicators
- Active user tracking
- Real-time activity feed
- Typing indicators

#### 4. Workspace Features

- Collections management
- Team member management
- Merge request handling
- Activity tracking
- Version history

### Security & Access Control

- Granular permission settings
- Secure member invitations
- Activity audit logs
- Private/public visibility options

## Getting Started

1. Create a new workspace (Personal/Team/Public)
2. Configure workspace settings
3. Invite team members
4. Start organizing collections
5. Monitor activity through the dashboard
